ЛАБОРАТОРНАЯ РАБОТА № 1
ОТВЕТЫ НА КОНТРОЛЬНЫЕ ВОПРОСЫ

1. Чем отличаются рабочий каталог, индекс и репозиторий?

Рабочий каталог содержит доступные для редактирования файлы проекта. Индекс хранит подготовленный снимок изменений, которые попадут в очередной коммит. Каталог .git содержит объекты, ссылки, конфигурацию и историю репозитория.

2. Какие состояния принимает файл и как выполняются переходы?

Неотслеживаемый файл становится подготовленным после git add; отслеживаемый файл после редактирования становится modified; git add вновь переносит изменения в staged, а git commit фиксирует их в истории. Команда git restore --staged снимает изменения с индекса без удаления рабочего файла.

3. Почему нельзя произвольно изменять сведения об авторе уже опубликованных коммитов?

user.name и user.email входят в метаданные каждого коммита. Изменение уже опубликованного коммита меняет его идентификатор и требует переписывания общей истории; это осложняет синхронизацию и аудит авторства.

4. Чем отличаются уровни local и global? Почему выбран local?

Local задается конфигурацией конкретного репозитория и имеет приоритет над global. Global применяется к репозиториям текущего пользователя, если локально значение не переопределено. В работе local позволяет не затрагивать остальные проекты.
